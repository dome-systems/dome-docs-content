**Manage** administers the Dome platform: workspace defaults, who can administer Dome, tenants and workspaces, configuration import and export, audit export, and billing.

If you are standing up a new boundary, start with [Environments](/manage/environments). The other pages assume a workspace already exists.

These grants and settings are platform administration only. They do not authorize agent tool or model calls, attach agent-facing resources, or replace investigation under [Operate](/operate). See [Scopes](/concepts/platform/scopes) for tenancy boundaries and [Permissions](/concepts/platform/permissions) for platform RBAC versus runtime agent authorization.

## Typical workflow

1. [Prepare environments](/manage/environments) to create tenants and workspaces, then select a CLI context.
2. [Configure platform](/manage/settings) to set workspace defaults and review configuration changes in audit.
3. [Enable public preview](/manage/public-preview) when you want to use public-preview features offered to your organization.
4. [Manage access](/manage/access) to assign workspace members and create or revoke scoped platform API keys.
5. [Import and export configuration](/manage/import-export) to move reviewed resources between compatible scopes.
6. [Export data](/manage/export) to choose a format, configure a destination, schedule runs, and monitor forwarder health.
7. [Review billing](/manage/billing) for plan status, usage, and invoices.

Configure audit destinations and enterprise single sign-on under [Operate → Integrations](/operate/integrations).
