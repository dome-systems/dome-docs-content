---
title: dome version
description: Show CLI version information
---

`dome version` reports which build of the CLI you are running and can check whether a newer one is available. Include this output when reporting a problem.

## Version

```bash
dome version
```

Show the dome CLI version, commit, build time, Go version, and OS/architecture.

```bash
dome version
```

| Flag | Type | Description |
|------|------|-------------|
| `--check` | bool | Check for a newer version |
