Five tutorials, in no particular order. Read the one that matches the problem in front of you.

<IconCards>
  <IconCard icon="bot" title="Run a managed agent" href="/build/agents/managed">
    Let Dome run an agent worker on demand, on a schedule, or from a signed webhook.
  </IconCard>
  <IconCard icon="network" title="Use Dome as an MCP gateway" href="/tutorials/production/use-dome-as-an-mcp-gateway">
    Let Cursor, Claude Code, or Codex sign in with your own Dome account and call MCP tools, individually audited.
  </IconCard>
  <IconCard icon="route" title="Use Dome as a model broker" href="/tutorials/production/use-dome-as-a-model-broker">
    Hold the provider key server-side and let Cursor, Claude Code, or Codex call any model, not just their own.
  </IconCard>
  <IconCard icon="key-round" title="Govern callers with OIDC" href="/tutorials/production/govern-callers-with-oidc">
    Authorize a shared assistant from each signed-in employee's identity provider token, then inspect every caller.
  </IconCard>
  <IconCard icon="server" title="Deploy an always-on agent" href="/tutorials/production/deploy-your-agent/always-on">
    Build a request-serving HTTP agent, deploy it as a private container service, and verify its governed calls.
  </IconCard>
  <IconCard icon="zap" title="Deploy an event-driven agent" href="/tutorials/production/deploy-your-agent/event-driven">
    Build a bounded handler, invoke it once, then attach a schedule without moving credentials into the function.
  </IconCard>
</IconCards>
