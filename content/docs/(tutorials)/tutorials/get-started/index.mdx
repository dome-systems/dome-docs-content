description: Four tutorials that build one governed workspace, in order

Each one builds on the workspace the one before it left behind, and every one ends with a governed call you can verify in the audit trail.

<RowCards>
  <RowCard step={1} title="Govern your first agent" href="/tutorials/get-started/govern-your-first-agent">
    Allow employee lookups, redact contact details, and deny payroll — from Cursor, Claude, or curl.
  </RowCard>
  <RowCard step={2} title="Call a model through a pool" href="/tutorials/get-started/call-a-model-through-a-pool">
    Route chat through a model pool with failover, and keep your provider key server-side.
  </RowCard>
  <RowCard step={3} title="Build a governed app" href="/tutorials/get-started/build-a-governed-app">
    Wire model and tool calls into one application. Watch allow, redact, and deny.
  </RowCard>
  <RowCard step={4} title="Govern per end user" href="/tutorials/get-started/govern-per-end-user">
    Give each person different tool access and different answers from the same agent.
  </RowCard>
</RowCards>
