# Dome documentation content

This repository contains the released, public MDX and assets rendered by the
Dome Developer Portal. It is intentionally content-only: it contains no
application code, deployment configuration, analytics credentials, identity
configuration, private product plans, or unreleased release notes.

## Publishing model

The portal production build consumes a pinned revision of this repository. New
or non-public material is first reviewed in `dome-docs-content-private`; only
an explicit promotion pull request may copy approved files here.

## Contributions

Public contributions are welcome for released documentation. Do not include
customer data, secrets, roadmap details, or unreleased functionality. The
portal validates the public-content boundary before release.
